# HTML & CSS Multi-Page Design

A simple multi-page website project created using HTML and CSS.

## Features

- Styled headings and sections
- Different table designs
- Custom colors and borders

- Organized page layouts

- HTML5
- CSS3

- HTML files – Website content and structure
- CSS file – Styling and page layouts
